# Step 03: Categories & wallets (basic)

**Status:** ✅ Done · **PRD:** 6.3, 6.4

## What was built
- 9 default categories created for each new user (Food, Transport, Bills, Shopping, Health, Education, Entertainment, Savings, Miscellaneous).
- A Cash wallet created for each new user.
- `GET /categories`, `GET /accounts`, `POST /accounts`.
- Add a wallet straight from the Add Expense sheet.

## Known gaps (picked up later)
- Editing, deleting, and setting a balance on a wallet: Step 11.
- Category icons are emojis: Step 10.
- Custom categories (PRD 6.3) aren't built yet: Step 11.
